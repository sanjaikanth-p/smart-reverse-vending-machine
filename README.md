# Smart Reverse Vending Machine

### An ESP32-Based Smart Recycling and Reverse Vending System

A multidisciplinary engineering project exploring an automated vending system designed around the collection and identification of recyclable items.

---

## 📌 Project Overview

The Smart Reverse Vending Machine was developed as a multidisciplinary project involving Electronics and Computer Science students.

The project explores the use of an ESP32-based system to support an automated reverse vending machine concept.

The work involved hardware and software planning, system-level design and coordination between different technical domains.

## 🎯 Objectives

- Develop a smart reverse vending machine prototype.
- Explore embedded system integration using ESP32.
- Plan hardware and software components.
- Investigate automated item identification and vending workflows.
- Apply multidisciplinary engineering principles.

## 🧩 System Concept

The project is based on the reverse vending machine concept, where an item is submitted to the machine and the system is designed to support an automated processing workflow.

The intended system involves:

1. Item submission.
2. Item detection and identification.
3. Embedded system processing.
4. System response based on the detected item.
5. Reward or transaction handling as part of the overall concept.

## 🔧 Development Work

The project involved hardware and software planning as part of a multidisciplinary team.

The ESP32 platform was selected as the embedded system foundation.

The project was developed across two semesters, allowing the team to work on its system design and implementation.
